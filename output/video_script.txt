[00:45 - 01:30] SCENE 2: THE PROBLEM WITH TRADITIONAL AI
--------------------------------------------------------------------------------
[ON SCREEN]:
Split screen comparison. On the left: a ChatGPT window showing a prompt asking for
financial math, with a red highlight on hallucinated numbers. On the right: a messy,
unaligned Word document with broken tables.

[SPEAKER / VOICEOVER]:
"Before we look at the code, let's understand why we needed a multi-agent system in the
first place.

Today, a lot of people try to use single AI chat prompts for financial analysis. But
single language models have two huge flaws when it comes to serious business.

First, they hallucinate numbers. A language model is designed to predict the next word
that sounds nice; it is not a calculator. If you ask it to calculate the standard deviation
of ten companies' profit margins in its head, it will often give you a number that sounds
convincing, but is completely made up.

Second, a single model tries to do too many things at once: searching the web, formatting
data, doing math, and writing sentences. It gets confused, loses context, and produces
unformatted walls of text that no CEO would ever want to read.

Marketverse fixes this completely by using the concept of specialized division of labor.
Instead of one AI doing everything poorly, we have four distinct AI personas that work
together like a real Wall Street research desk."


[01:30 - 02:45] SCENE 3: THE TEAM ARCHITECTURE & SUPERVISOR MANAGER
--------------------------------------------------------------------------------
[ON SCREEN]:
A clean architectural flowchart diagram appears.
At the top: Supervisor Manager LLM (GPT-4o).
Three arrows branch downward into three distinct agent cards:
1. Lead Researcher (Market Research Specialist)
2. Data Analyst (Financial Data Analyst)
3. Content Writer (Technical Reports Writer)

[SPEAKER / VOICEOVER]:
"Let's meet the team.

Marketverse is built on top of the CrewAI framework using what is called a hierarchical
process structure—or 'Process dot hierarchical'.

Think of this like a modern investment firm. At the top sits our Supervisor: the
Manager LLM. The manager does not do manual grunt work. Its job is to oversee the mission,
break the user's request into smaller tasks, dynamically delegate assignments to the right
specialist, and double-check every output before giving it final approval.

Beneath the manager are three specialized autonomous agents:

First is our Lead Researcher, whose official title is 'Market Research Specialist'. This
agent is our digital detective. Its only mission is to search the web, locate corporate
earnings releases, find industry growth drivers, and scrape raw web pages.

Second is our Data Analyst, titled 'Financial Data Analyst'. This agent is our mathematical
guardian. It never searches the web and it never writes fluffy prose. Its entire job is
to open tabular spreadsheets, clean up messy numbers, calculate exact statistical distributions
using Pandas, and verify that all numbers are 100% consistent.

Third is our Content Writer, titled 'Technical Reports Writer'. This agent is our master
storyteller. It takes the qualitative research from the researcher and the verified math
tables from the analyst, and weaves them together into an authoritative, institutional-grade
market report."


[02:45 - 04:00] SCENE 4: CUSTOM TOOLS IN ACTION (SCRAPING & PANDAS MATH)
--------------------------------------------------------------------------------
[ON SCREEN]:
Code editor view (VS Code) showing `crew/tools/scraper_tool.py` and
`crew/tools/financial_tool.py`.
The camera zooms in on the `@tool` decorator, BeautifulSoup HTML cleaning, and the
Pandas `df.describe().to_markdown()` function.

[SPEAKER / VOICEOVER]:
"Now, how do these agents actually interact with the real world? They use Custom Tools.

In CrewAI, a tool is a Python function decorated with the at-tool decorator. We built
two critical custom tools for Marketverse:

Tool number one is our Web Scraper Tool. When the researcher needs live intelligence,
it calls this tool. It connects directly to search APIs like Tavily and SerperDev. Once
it gets the top search results, it uses Python's requests and BeautifulSoup libraries to
visit those web pages in the background, rip out all the annoying ads, scripts, and
navigation headers, and extract pure, high-density business text.

Even better, we built in an automatic offline fallback mode. If your internet ever drops
or if you don't have paid API keys, Marketverse automatically supplies high-fidelity
curated datasets so the system never crashes!

Tool number two is our Financial Data Parser. This tool uses Pandas—the world's most
trusted data science library. When corporate metrics are fed into it, the tool automatically
cleans up messy human formatting—it strips away dollar signs, commas, and percentage
symbols.

Then, it runs real mathematical functions: it computes the exact average, the minimum,
the maximum, the median, and the standard deviation across all tracked metrics, and
converts that table into clean Markdown text.

Because the math happens in compiled C-code through Pandas, it is mathematically
impossible for our agents to hallucinate the numbers!"


[04:00 - 05:15] SCENE 5: PROGRAMMATIC PDF GENERATION WITH REPORTLAB
--------------------------------------------------------------------------------
[ON SCREEN]:
Open PDF viewer showing `output/market_report.pdf`.
The camera pans over the full-width deep navy header banner, the crisp typography,
the styled zebra-striped data table, and zooms into the bottom right corner showing
"Page 1 of 3", "Page 2 of 3".

[SPEAKER / VOICEOVER]:
"Once the Content Writer synthesizes the final draft, Marketverse doesn't just hand
you a messy text file. It compiles a publication-grade, A4 PDF report using ReportLab.

A lot of software projects take the easy way out by using HTML-to-PDF converters that
often break tables across pages and cut off text. We didn't do that. We built a direct
programmatic document pipeline using ReportLab's Platypus typography engine.

Take a look at this output:

At the top, we have a custom full-width corporate header banner in Deep Slate Navy and
Royal Blue, displaying the document title, generation date, and security classification.

Below that, every section is cleanly styled with explicit line leading and accent dividers.

Then look at this table! This is our Pandas summary matrix rendered as a styled ReportLab
table flowable. It features bold navy headers, soft borders, and alternating zebra rows
so your eyes never lose their place when reading across large financial figures.

And look at the footer: it says 'Page 1 of 3', 'Page 2 of 3'. We achieved this by
subclassing ReportLab's canvas into a custom class called NumberedCanvas. It performs
a two-pass rendering trick that saves pages in memory first, figures out the exact total
page count, and then paints the running headers and footers onto every single page.
It is completely bulletproof."


[05:15 - 06:15] SCENE 6: EXECUTION BENCHMARKING (BENCHMARKS.JSON)
--------------------------------------------------------------------------------
[ON SCREEN]:
VS Code showing `benchmarks.json`.
Highlighting the `routing_history` array, `duration_seconds` for each step, and
the `agent_benchmarks` summary.

[SPEAKER / VOICEOVER]:
"In production engineering, you have to measure performance. You need to know how fast
your agents are working and track how tasks are being routed.

Marketverse features a built-in telemetry tracker called BenchmarkTracker. Every time a
workflow starts, it kicks off a microsecond-precision wall-clock timer.

As the Manager LLM delegates Task 1 to the Researcher, Task 2 to the Analyst, and Task 3
to the Writer, the tracker logs:
- The exact start and completion timestamps
- The duration of each individual task in seconds
- The delegating supervisor
- And a preview of the task output.

All of this telemetry is automatically saved into a local file called benchmarks.json.
This gives engineering teams complete transparency, allowing you to audit agent behavior,
detect latency bottlenecks, and measure token usage over time."
